# Projeto de Data Warehouse e Análise de Dados

Este projeto demonstra uma solução moderna de Data Warehouse utilizando SQL Server, incluindo processos de ETL, modelagem de dados e análise.

--- 

## Requisitos do Projeto

### Construção do Data Warehouse

#### Objetivo 

O objetivo deste projeto é o desenvolvimento de um Data Warehouse utilizando SQL Server para consolidar dados sobre vendas, possibilitando a criação de relatórios analíticos para apoiar tomadas de decisão empresariais.

### Especificações 

- **Fontes de Dados**: Dados de dois sistemas fonte (ERP e CRM) são disponibilizados através de arquivos CSV.
- **Qualidade dos Dados**: Limpeza e resolução de problemas relacionados a qualidade dos dados são realizadas antes da análise.
- **Integração**: As duas fontes de dados são combinadas em um modelo de dados único e *user friendly*, voltado para consultas analíticas.
- **Escopo**: Apenas o último *dataset* é considerado; Histórico de dados não é necessário
- **Documentação**: Apresenta documentação clara sobre o modelo de dados para apoiar analistas de dados e tomadores de decisão.

---

### BI e Relatórios (Análise de Dados)

#### Objetivo 

Desenvolver análises baseadas em SQL para fornecer *insights* detalhados sobre:
- **Comportamento de clientes**
- **Performance de produto**
- **Tendências de vendas**
